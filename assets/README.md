## `nog-pick-pulse-dashboard.png`
**What it is:** the "NOG Distribution Ops — Pick Pulse" dashboard, a work in progress built for Hy-Vee distribution center operations. It shows live warehouse (WMS) workload by pick area (Floor, Tower, PIR, Tobacco, Bulk, Seasonal): cases remaining, cases packed per hour, and hours to clear.

**Where to use it:**
- **Intro (Oracle → Hy-Vee):** "Here's what tech looks like at a grocery company."
- **Section 5, level 3 "Create" / level 4 "Delegate":** an example of building a real tool with AI, beyond just asking it questions.
- **Myth 4, "companies need their own LLM":** this tool connects AI-built software to the company's *own* data rather than training a new model.
- **For CS and Agriculture students:** logistics and supply chain are data-heavy jobs.
